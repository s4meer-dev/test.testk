# Artisanal Coffee Shop ☕

A responsive, interactive web application showcasing a modern coffee shop menu, online ordering simulator, and cafe ambience.

## Features
- **Interactive Menu**: Browse espresso, cold brews, and seasonal artisanal beverages.
- **Dynamic Cart**: Real-time order calculation with checkout simulation.
- **Responsive Design**: Mobile-first layout crafted with modern CSS.

## Getting Started

Simply open `index.html` in any modern web browser or serve via a lightweight HTTP server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```

Navigate to `http://localhost:8080` to experience the cafe interface.

## Tech Stack
- HTML5 Semantic Structure
- Vanilla CSS3 Animations & Responsive Grid
- Modern JavaScript (ES6+) DOM Manipulation
